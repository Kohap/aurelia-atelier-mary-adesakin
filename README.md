# Adesakin Mary Damilola Portfolio

Original thread painting portfolio and collector inquiry site for Nigerian artist Adesakin Mary Damilola.

## Preview Locally

Open the static page directly:

```bash
open index.html
```

## Project Structure

```text
.
├── index.html
├── assets/
```

## Current Features

- Artist biography and statement
- Original artwork catalogue
- Collector shortlist
- Acquisition inquiry email draft
- Exhibition history
- Studio contact details
- SEO and social sharing metadata

## Publishing

This is a static site. It can be published with GitHub Pages from the `main` branch using `index.html` at the repository root.
